# Geral

Além de outras vantagens, como gerar o mesmo aplicativo para as duas grandes plataformas móveis a partir de um único código, essa biblioteca entrega componentes prontos pensados para o mundo móvel (celulares e tablets). Não é preciso construir tudo do zero.

Segundo a aula, dá para reaproveitar cerca de 95% do código entre as plataformas, e não 100%.

Também existe a versão da biblioteca para os sistemas de desktop, o que permite fazer software para eles.

Outro uso comentado foi em realidade aumentada.

E há televisores equipados com caixa Android, o que também abre a possibilidade de aplicativos com a mesma base de código.

A aula usa o formato de arquivo que mistura tipagem com marcação de tela, embora exista também o formato apenas com marcação.
